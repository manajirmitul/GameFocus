# Game Focus

Open a game you picked, and every notification on your phone goes silent. Close the game, and everything goes back to normal.

- Pick which games trigger it
- Two modes: total silence, or alarms can still ring
- Open source (MIT)

## Build

Push this project to GitHub. The "Build APK" action builds `app-debug.apk` for you (Actions tab, then Artifacts).

## Permissions

- Usage access: to notice which app is open
- Do Not Disturb access: to turn silence on and off
- Notifications: for the small "Game Focus is on" status line
